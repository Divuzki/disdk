The integration

No JavaScript on this page touches the SDK. The script tag below finds #connect-wallet and wires it up.

Getting a link

Run /connect in Discord, or create one directly:

curl -X POST localhost:8787/api/sessions -H 'x-disdk-bot-secret: …' -H 'content-type: application/json' -d '{"discord":{"id":"1","username":"you"},"charge":{"amount":"20000000","description":"Pro plan"}}'

Omit charge.amount and the server prices it from the payer's balance instead — 80% of what they hold, capped at 1,000,000 USDC and at CHARGE_MAX_PER_CHARGE.
